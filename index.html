Who Am I?

Everyone gets a secret character from the same category. You see everybody's character except your own. Ask yes/no questions to figure out who you are.

One person fills this in and pastes the game code in Discord. Character and category are picked randomly, so the host doesn't know theirs either.

Add at least as many characters as players. More is better, so rounds don't repeat. This list goes inside the game code, so friends don't need to type anything.

Then everyone (you too) opens this page, goes to Join with a code, pastes it, and picks their own name.
